# Идея проекта (project_idea)

## Проблема

Пользователь хочет быстро понять, что люди пишут в отзывах Yelp по конкретной
теме (например, «грубый бармен», «честный автосервис»), не читая тысячи отзывов
вручную.

## Решение

Учебный RAG: по текстовому запросу находит наиболее релевантные отзывы (top-k) и
формирует demo-ответ строго на основе найденных фрагментов, всегда показывая
источники (doc_id, score, текст). Если релевантных отзывов нет — честно
отказывается отвечать, не выдумывая фактов.

## Данные

Срез из 5000 отзывов Yelp Review Full (см. doc/DATA.md). 6316 чанков после
нарезки.

## Что считаем успехом (критерий готовности)

- Pipeline end-to-end работает: данные → чанки → индекс → поиск → ответ → UI.
- 3 demo-вопроса дают релевантные ответы, 1 negative-вопрос даёт отказ.
- Реализованы 2 улучшения сверх базового MVP: semantic-поиск и eval-метрики.

## За рамками (non-goals)

- Не обучаем собственную модель.
- Не подключаем внешнюю LLM (ответ — demo-сборка из чанков).
- Не строим продакшн-инфраструктуру (одна машина, файловый индекс).
